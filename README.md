# Music

Application Android de journal musical personnel centrée sur l'analyse émotionnelle, l'import de fichiers audio locaux, les liens YouTube/YouTube Music et les recommandations personnalisées.

## Objectifs initiaux
- Application Android installable
- Interface sombre et moderne
- Journal des morceaux
- Analyse audio locale
- Profil émotionnel personnel
- Recommandations personnalisées
- Architecture prête pour OAuth Google/YouTube et services externes
