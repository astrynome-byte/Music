# Job unique de qualification native du fonds OpenScore

Préparé uniquement, sans publication ni exécution Windows. Le pack optionnel reste hors du MSI 2007 figé. Le seul programme utilisé sera l’EXE 2006 existant : SHA-256 `c29d7c8c76b213b79d7390acd65cbabc6fb940f06e3e7f86c0ce60be7e9b9520`, ZIP `b6b6bb9160250282879543b44e1ca8217494285e86c47fb2003f8b24dd93954c`, source.json `0d6c5944374cfa2b58ee8f81a3912b36585ed263ed79ffb3ff1968f2bd07ca1b`. Les vérificateurs source/artefact sont les mêmes octets que ceux de la qualification réelle du stage. Le workflow exige le namespace de provenance `combined-2006-source` déjà publié.

L’archive de contenu est restaurée et chaque membre est authentifié avant de lancer le moteur natif. Chaque pièce passe une copie indépendante à quatre commandes CLI réelles : ouverture/import avec PDF, sauvegarde MSCZ, réouverture de la sauvegarde avec PDF, WAV depuis la sauvegarde. Les notes, gains, choix d’instrument et timbres ne sont pas réécrits. Les PDF doivent avoir leurs marqueurs de début et fin ; les versions natives sont lues sans modifier les originaux et comparées sur les nombres de parties/portées/mesures, hauteurs et fragments de paroles. Cette comparaison grossière ne valide pas tout le rythme, les articulations ou le contenu syllabique.

Chaque WAV doit provenir d’un processus ayant terminé avec le code 0, être fini, contenir des échantillons finis, être non muet et ne pas atteindre le plein niveau numérique. L’analyseur WAV réutilisé est inchangé. Les paramètres audio natifs et les timbres encodés sont conservés dans les rapports ; aucune absence d’avertissement ni sauvegarde dans la même session après lecture n’est revendiquée. Une ressource réellement listée ou chargée ne se déduit pas d’un export save-only. Les durées WAV mesurées seront des durées de rendu, sans valider une interprétation de concert.

Le helper de profil et le Job natif possédé sont réutilisés sans changement. Le profil doit être initialement absent. Après contrôle des marqueurs, le seul INI possédé est configuré WASAPI pour les exports CLI ; aucun endpoint ASIO n’est enregistré ou lancé. Le Job doit prouver le drainage des descendants avant le nettoyage du profil et sa fermeture finale. Toute terminaison forcée interdit le statut PASS. Les fichiers du stage et tous les originaux du contenu sont vérifiés avant/après. Les échecs de conversion, saturation, timeout ou nettoyage restent des échecs documentés.

Le job nécessite Windows x64 GitHub-hosted et Python 3.12, sans compilation ni installation de l’application. Les artefacts de preuve sont retenus 14 jours par GitHub, sans promesse de lien public de livraison. Il ne teste ni import du catalogue GUI, édition, lecteur d’écran, impression visuelle, voix humaine, instrument commercial ou écoute. Les sons de substitution et les sept fichiers de formats anciens restent explicitement à contrôler visuellement et musicalement.

Les scripts QA sont sous GPL-3.0-only, licence jointe ; les dix encodages et leur notice sont dans le pack CC0. Aucun accès MuseScore.com, audio externe ou scan IMSLP n’est requis.
