Cadence — complément de sons VSCO CE expérimental 1.1.0-exp.1

Ce lot contient trois banques SF2 facultatives :
- Violoncelles ensemble avec vibrato : 48 400 382 octets, notes MIDI 36 à 77, banque 0 / programme 42 (43 dans une liste numérotée à partir de 1).
- Trompette avec vibrato : 21 599 476 octets, notes MIDI 52 à 84, banque 0 / programme 56 (57 à partir de 1).
- Contrebasse avec vibrato : 47 966 050 octets, notes MIDI 24 à 60, banque 0 / programme 43 (44 à partir de 1).
Total des SF2 : 117 965 908 octets, environ 112,5 Mio, hors notices et sources.

Installation sans outil de développement :
1. Vérifie le fichier avec SHA256SUMS si tu le souhaites. Extrais l'archive de sons dans un nouveau dossier ; elle contient les trois SF2 et leurs notices.
2. Dans Cadence, ouvre Préférences > Dossiers et repère le dossier SoundFonts. Copie les SF2 dans ce dossier ; tu peux également utiliser la carte correspondante du gestionnaire de collections si ta version de Cadence la propose, avec son bouton d'import de fichier local.
3. Ferme et relance Cadence si les nouveaux sons ne sont pas encore listés. Dans le mixeur, choisis la banque correspondant à chaque piste. Enregistre la partition pour conserver les identifiants et réglages.
4. Garde MS Basic pour les autres instruments et les notes hors des plages annoncées. Si une banque est absente sur un autre ordinateur, réinstalle le même fichier vérifié ou choisis explicitement un son de remplacement dans le mixeur.

Résultat musical et limites : une seule articulation tenue avec vibrato, avec couches de vélocité. Aucun legato, staccato, portamento ou transition enregistrée supplémentaire n'est ajouté. Les échantillons originaux ne sont pas bouclés : une tenue très longue finit avec son enregistrement, même si la note reste enfoncée. Attaque et relâchement fixes. Les originaux PCM 24/32 bits sont ramenés de façon déterministe en PCM 16 bits sans dither ; stéréo et zones liées sont conservées. Le gain vise le facteur EMU 0.4 de FluidSynth dans Cadence ; son interprétation peut différer avec un autre lecteur SF2. Ajuste les volumes et la réverbération selon ta partition.
