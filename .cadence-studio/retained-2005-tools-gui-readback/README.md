# Lecture complète de deux rapports existants GUI3

Ce lecteur reprend seulement l'artefact 13953546227 du run 43236835262.
Il exige les tailles et SHA originaux de `uia-report.json` et `close-report.json`
déjà obtenus dans les enveloppes du journal authentifié. Il restitue leurs
octets complets en base64 borné et conserve les fichiers identiques.

Il ne lance ni application, ni SDK, ni interface, ni réseau du produit.
Aucun résultat musical ou nouveau test GUI n'est déduit de cette lecture.
L'objectif est de diagnostiquer les actions omises de la projection à 80 actions
avant toute autre modification du helper. Le petit ZIP n'a pas pu être obtenu
localement : le proxy a refusé son domaine de téléchargement avec HTTP 403.

La recette est préparée pour revue et publication par le parent. Elle n'a pas
été déclenchée ici. Le contrôle local porte sur la syntaxe Python/YAML et le
refus d'un répertoire sans les rapports ; les vrais octets restent à relire.
