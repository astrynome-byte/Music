# Copies natives pour les futurs essais de bibliothèque

Deux compositions originales du corpus Cadence, sous **CC0-1.0** : piano et
chant. Elles ont déjà été importées puis réouvertes par la référence officielle
Linux MuseScore Studio4.7.6. Ces fichiers MSCX sont des copies **octet pour
octet** de ces résultats ; aucune nouvelle conversion ni exécution UI n'a eu lieu.

`manifest.json` conserve titres, compositeur, sources MusicXML, provenance de
conversion, tailles et SHA-256. Les originaux ont été contrôlés avant et après
la copie et sont inchangés. Les notices CC0 restent dans les partitions.

Utiliser ces données **seulement si l'onglet Bibliothèque locale est réellement
activé** : les recopier dans un nouveau dossier `RUNNER_TEMP`, vérifier leurs
empreintes avant et après les essais, puis sélectionner ces nouvelles copies.
Ne jamais utiliser les chemins des originaux comme entrées des gestes UI.

Le fichier `.gitattributes` désactive la conversion de fins de ligne des MSCX
pour préserver leurs empreintes lors d'un futur checkout Windows. Ces données
ne prouvent aucun succès d'ajout, favoris, recherche, redémarrage ou ouverture.
